GITHUB SUBMISSION

How to submit your request

1. Open the GitHub Issue page

If you are already logged in to GitHub, you will go directly to the Airi issue page. You do not need to log in again.

If you are not logged in, GitHub will first open the Login page. Log in to your existing account, or create a new GitHub account. After login or account creation, GitHub will automatically continue to the correct Airi issue page.

2. Check the Issue title and message

The Title is automatically filled with your selected category: Report, Feature Idea, or Help. Your Discord username and message are also filled in automatically.

3. Upload your image

On the GitHub issue page, use the Add Files option below the description box. Select your screenshot or image and wait for the upload to finish.

You can add your image directly on GitHub. This website does not upload or store your image.

4. Submit your request

After checking the title, Discord username, message, and image, scroll down to the bottom of the GitHub page.

Tap the green Create button to submit the issue. On some GitHub pages, this button may be shown as Create issue or Submit new issue.

Important: If you are already logged in, GitHub opens the issue page directly. If you need to log in or create an account, GitHub returns you to the correct issue page automatically after authentication. Finally, use Add Files to upload your image and tap the green Create button to submit.
