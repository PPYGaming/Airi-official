# Airi Dashboard

GitHub Pages-ready Airi dashboard.

## Files
- `index.html` — website
- `airi-logo.gif` — animated Airi logo
- `airi-poster.png` — background artwork
- `.nojekyll` — GitHub Pages helper

## GitHub Pages
Repository → Settings → Pages → Deploy from branch → `main` → `/ (root)`.

Replace `airi-logo.gif` with another GIF using the same filename if you want a different animated logo.
